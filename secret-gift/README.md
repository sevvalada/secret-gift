# 🎁 SecretGift

SecretGift, arkadaşlar, aile veya çalışma arkadaşları arasında kolayca Secret Santa çekilişi oluşturmayı sağlayan modern bir React web uygulamasıdır.

## ✨ Özellikler

- 🎀 Katılımcı ekleme
- ✏️ Katılımcı düzenleme
- 🗑️ Katılımcı silme
- 🔐 Katılımcı sonuçlarını gizli şekilde görüntüleme
- 🎲 Rastgele Secret Santa çekilişi
- 🚫 Kişinin kendisiyle eşleşmesini engelleme
- 💾 LocalStorage ile verileri saklama
- 📱 Responsive ve mobil uyumlu tasarım
- 🌸 Modern açık pembe ve yılbaşı temalı arayüz

## 🛠️ Kullanılan Teknolojiler

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- LocalStorage
- Git & GitHub

🚀 Kurulum
Projeyi bilgisayarınıza indirdikten sonra:
npm install

Uygulamayı geliştirme modunda çalıştırmak için:
npm run dev

Ardından tarayıcıdan:
http://localhost:5173

adresini açabilirsiniz.
📦 Production Build
Projeyi production için hazırlamak:
npm run build

🎯 Projenin Amacı
Bu proje, React ile modern web arayüzleri geliştirme, component yapısı, routing, state yönetimi, LocalStorage kullanımı ve temel CRUD işlemlerinin uygulanmasını pekiştirmek amacıyla geliştirilmiştir.
